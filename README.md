# LLM Text Classification

Исследование классификации тональности твитов о COVID-19 с помощью больших языковых моделей **Mistral AI** без дополнительного обучения.

Цель проекта — повысить качество бинарной классификации текстов (*positive / negative*) за счёт выбора модели, настройки инструкций и использования few-shot примеров.

## Эксперименты

В работе последовательно исследованы:

1. **Выбор LLM** - сравнение моделей Ministral 3B и 8B.
2. **System prompt** - изменение инструкций на основе анализа ошибок классификации.
3. **Few-shot learning**  подбор количества и состава примеров в промпте.
4. **Размер модели** - сравнение Ministral 8B и 14B при одинаковых инструкциях.
5. **Температура генерации** - проверка влияния параметра `temperature` на точность.

Для оценки использовались Accuracy, Precision, Recall и F1-score.

## Результаты

| Конфигурация | Accuracy |
|---|---:|
| Ministral 3B — baseline | 0.61 |
| Ministral 8B — исходный промпт | 0.90 |
| Ministral 8B — расширенный system prompt | 0.74 |
| Ministral 8B — сокращённый system prompt | 0.86 |
| Ministral 8B — six-shot | 0.92 |
| **Ministral 8B — four-shot** | **0.94** |
| Ministral 14B — four-shot | 0.83 |
| Ministral 8B — four-shot, temperature = 0 | 0.94 |

**Лучший результат — Accuracy 0.94 и F1-score 0.9286.**

Эксперименты проводились на выборке из 100 твитов. Поскольку настройки подбирались на этой же выборке, полученные метрики не являются оценкой на независимой тестовой выборке.

## Используемые технологии

Python, Pandas, Mistral API, Scikit-learn, асинхронные запросы к LLM и few-shot prompting.

## Запуск

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скачайте [датасет](https://disk.yandex.ru/d/ErrpfkgFkdtOIQ) и положите `tweets_coronavirus_final.csv` рядом с ноутбуком.

3. Создайте `.env` и добавьте API-ключ:

   ```env
   MISTRAL_API_KEY=your_api_key
   ```

4. Откройте `raif_fcs_2_final.ipynb` в Jupyter или VS Code и выполните ячейки.

Для повторного запуска требуется доступ к Mistral API; запросы могут расходовать платную квоту. Исходный датасет и API-ключ не публикуются в репозитории.
