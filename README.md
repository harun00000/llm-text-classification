# LLM Sentiment Classification

Исследование методов повышения качества классификации тональности текстов с помощью больших языковых моделей **Mistral AI** и prompt engineering.

Задача — определить тональность твитов о COVID-19: **positive** или **negative**. Исходные метки `Positive` и `Extremely Positive` объединяются в положительный класс, остальные — в отрицательный.

## Подход

Вместо дополнительного обучения модели используется **prompt engineering**: изменение инструкций, добавление примеров и настройка параметров генерации.

В ходе работы проведены пять экспериментов:

1. **Выбор модели:** сравнение Ministral 3B и 8B.
2. **System prompt:** анализ ошибок и изменение инструкций классификатора.
3. **Few-shot prompting:** сравнение наборов из шести и четырёх примеров.
4. **Размер модели:** проверка Ministral 14B при сохранении промптов.
5. **Температура генерации:** сравнение значений `0.1` и `0`.

Для оценки использовались Accuracy, Precision, Recall и F1-score.

## Результаты

| Конфигурация | Accuracy |
|---|---:|
| Ministral 3B — baseline | 0.61 |
| Ministral 8B — исходный промпт | 0.90 |
| Ministral 8B — расширенный system prompt | 0.74 |
| Ministral 8B — сокращённый system prompt | 0.86 |
| Ministral 8B — six-shot | 0.92 |
| **Ministral 8B — four-shot** | **0.94** |
| Ministral 14B — four-shot | 0.83 |
| Ministral 8B — four-shot, temperature = 0 | 0.94 |

**Лучший результат: Accuracy 0.94 и F1-score 0.9286.**

Основное улучшение обеспечила замена модели Ministral 3B на 8B. Дополнительный прирост качества получен благодаря подбору few-shot примеров. Увеличение модели до 14B и снижение температуры не дали дальнейшего улучшения.

Эксперименты проводились на выборке из **100 твитов**. Промпты подбирались на этой же выборке, поэтому результаты не являются независимой оценкой обобщающей способности модели.

## Запуск

**1. Установить зависимости**

```bash
pip install -r requirements.txt
```

**2. Подготовить данные**

Скачать [датасет](https://disk.yandex.ru/d/ErrpfkgFkdtOIQ) и разместить `tweets_coronavirus_final.csv` в корне проекта.

**3. Настроить Mistral API**

Создать API-ключ в [Mistral AI Console](https://console.mistral.ai/) и добавить его в файл `.env`:

```env
MISTRAL_API_KEY=your_api_key
```

**4. Открыть ноутбук**

Запустить `sentiment_classification.ipynb` через Jupyter или VS Code и выполнить ячейки последовательно.

Для выполнения необходим доступ к Mistral API. Повторные запросы могут расходовать платную API-квоту, а результаты могут зависеть от доступности используемых моделей.
